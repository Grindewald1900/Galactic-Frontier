## 0. 核心判断（一句话）

功能框架已能跑通 **探索 → 战斗 → 采集 → 制造 → 交易 → 成长**，但视觉与交互仍偏开发后台。P6 最优先的不是换美术，而是：**舰桥成为主页**、**跨系统缺口可点击跳转**、**每屏只突出一个最值得做的主操作**。

---

## 1. 诊断

| 问题 | 表现 | 后果 |
| --- | --- | --- |
| 舰桥不是主页 | 战力/进度只是数字；五个同级 CTA；底部副本条与航网星图重复 | 玩家不知道「现在该做什么」 |
| 系统割裂 | 材料不足只提示，不跳转；十余个一级导航平铺 | 反复切页查缺口 |
| 反馈弱 | 空详情区、黑色列表、多色按钮语义混乱 | 缺少目标感与沉浸感 |

**非目标（P6）**：全量美术替换、`ProductionLine` 自动化实体、宇宙 M3、Online 玩家市场、战斗站位规则变更（见 [12-auto-battle.md](12-auto-battle.md)）。

## 3. 全局壳层

### 3.1 紧凑状态栏

顶栏不再重复「头像 + 名字 + Lv + 信用点 + 大片空白」。跨页常驻：

| 字段 | 来源（实现参考） |
| --- | --- |
| 舰长等级 | `Player` / meta |
| 信用点 | `CurrencyService` |
| 能源 / 燃料 | `ShipService` / 航行消耗（占位可后补数值） |
| 舰队占用 | `DeckService` Running / 泊位上限 |
| 制造队列 | `CraftingService` 进行中批次数 |
| 仓库容量 | `Inventory` 堆叠 / 上限 |
| 航行 / 挂机 | `NavigationService` + `ActionScheduler` 摘要 |
| 通知 · 任务 | 打开战情 / 任务抽屉 |

### 3.2 按钮语义（`NexusButtonRole`）

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| Primary | 金橙 `Gold` | 区域内 **唯一** 主操作 |
| Secondary | 深蓝 `Cyan` 底 | 次要确认 |
| Confirm | 绿 `Green` | 领取、开始、确认 |
| Danger | 红 `Red` | 停止、分解、清除 |
| Disabled | 灰 | 不可用（须 Tooltip 说明原因） |
| Link | 文字链接 | 跳转、辅助 |

**硬约束**：同一面板尽量只出现一个 Primary。

### 3.3 缺口跳转（`ShortageJump`）

所有「材料 / 货币 / 模块等级 / 招募券不足」须呈现可点击行：

```text
缺少铁矿 ×12　[前往采集]
缺少信用点 20　[出售物资]
制造技能不足（需要 10）　[培训 / 雇佣专家 / 购买成品]
```

实现复用 `ItemAcquireCatalog` + `ItemTooltip.Jump`；扩展非物品类缺口（模块、专业技能门槛、券）走统一 `ShortageJumpService` 解析器。  
技能门槛缺口须列出替代方案（培训、雇佣、购买、工坊补正），见 `19` 自动成长 §5.3。  
禁止仅 Snackbar「不足」而无跳转（Snackbar 可并存）。

### 3.4 任务追踪器

右侧可展开抽屉，替代任务一级页。**双层结构（Wave A）**：上层 **首章剧情**（`ChapterQuestService` / `chapter_v1`：标题、进度、Go、Claim）；下层 **新手航线**（`OnboardingService` / `onboarding_v1`）。`CommanderGoalService` 与舰桥主目标**优先** Active 剧情步骤。详见 [24-early-chapter-experience.md](24-early-chapter-experience.md) §6.5。

弥塔舰桥短句（示例，实现可走 `DialogueService` 或 `BridgeEventLog`）：

- 「外缘港信标已锁定。我们还活着——暂时。」
- 「人员信标还在响。先招募，再编队。」
- 「集火后排——科尔守住后方时胜率会跳升。」

| 分区 | 内容 |
| --- | --- |
| 进行中 | 当前步骤 + 进度 |
| 可领取 | 奖励 + 领取按钮 |
| 已完成 | 折叠归档 |
| 主线 / 订单 / 每日 | Tab 或筛选 |

已完成任务 **不再** 显示「前往」。新手线结束后须生成 **具体下一目标**（见 [17-sector-and-onboarding.md](17-sector-and-onboarding.md) §P6）。

## 4. 航网节点四轴展示（UI 层，Wave 1 不改存档）

由现有 `GridNodeState`、`GridEdgeTier`、`WorldService` 区域进度、`NavigationService` 停靠态 **组合展示**：

| 轴 | 取值示例 |
| --- | --- |
| 发现状态 | 未探测 / 已定位 / 已确认 |
| 航线状态 | 断航 / 临时通航 / 稳定 |
| 开发状态 | 未清理 / 已清理 / 已建设（建设后 MVP） |
| 舰队状态 | 未停靠 / 航行中 / 已停靠 |

右侧目标面板 **按轴组合只显示合理 CTA**（扫描、探针、规划航线、挑战、采集、建设、查看星港等）。「购买星域海图」放在扫描/情报区，不作为已知节点首要按钮。

星图布局：**地图 ≥70% 宽度**；节点列表收成可折叠导航日志；右侧仅目标面板。详见 [20](20-stellar-map-and-navigation.md) §P6。

## 5. 逐页目标布局（摘要）

### 5.1 舰桥 — 舰长决策面板

```text
当前主目标：修复矿脉支线航标
进度：2/4
瓶颈：扫描阵列 Lv.0 → 需要铁矿×12 [前往采集]
推荐行动：[前往外缘港采集]  （唯一 Primary）
```

布局：左舰队/航行 · 中主目标+生产 · 右可领收益/紧急 · 底缩略航网（点进星图）。删除底部重复副本条与五个同级 CTA。

### 5.2 星图 — 核心操作区

见 §4；熵雾节点用剪影/雾效，非完整行星；航线图例。

### 5.3 编队 — 五人阵型

```text
前排：[1] [2]
后排：[3] [4] [5]
```

中央空区改为阵型；点击角色显示职业/技能/占用/替换战力差；「停止」改为「停止{具体行动}」。右侧队伍优劣势与预估胜率（占位公式可后补）。详见 [11-deck-and-occupation.md](11-deck-and-occupation.md) §P6。

### 5.4 舰船 — 模块成长

每模块：Lv 当前→下一、属性 diff、解锁说明、材料缺口 + ShortageJump；「远征瓶颈」横幅链到推荐模块。

### 5.5 制造 — 三栏（UI；非 ProductionLine）

左：队列 · 中：配方+材料 · 右：产出/耗时/缺口。未选装备时不显示维修 CTA。Wave 1 不做自动采购/库存目标。

### 5.6 仓库 / 星港

正式名称、品质角标、来源/用途、当前需求标记、「缺口」筛选。行示例见评审 §7–§9。

### 5.7 角色 vs 卡牌

| 页 | 职责 |
| --- | --- |
| 角色 | 人物档案：立绘、能级、副本数、专长、故事、进入该角色卡列表 |
| 卡牌 | 实例管理：搜索、筛选、排序、堆叠、对比、强化/分解 |

### 5.8 招募

池视觉、重点角色、概率/保底、单抽十连成本、券来源（任务/兑换/领取）、揭示节奏与结果总结。

### 5.9 战斗结果

除返回外：下一推荐行动 + 缺口跳转；失败时短板提示。

### 5.10 设置

移入头像菜单；分组：账号 / 游戏 / 音频 / 显示 / 数据 / 开发者。「清空卡牌」仅开发者区 + 二次确认。

## 6. 优先级与改造顺序

| 优先级 | 页面 / 改动 | 原因 |
| --- | --- | --- |
| **P0** | 航网星图扩为核心区 | 最独特探索体验 |
| **P0** | 制造页三栏 + 缺口 | 中期循环是否成立 |
| **P0** | 编队阵型 + 选择上下文 | 策略可理解 |
| **P0** | 舰桥主目标 + 瓶颈 | 玩家知道下一步 |
| **P0** | 跨系统 ShortageJump | 闭环连接 |
| **P1** | 五级导航 + 状态栏 | 降低割裂 |
| **P1** | 招募表现 | 新手爽点 |
| **P1** | 仓库/商店正式名 + 用途 | 资源认知 |
| **P1** | 角色/卡牌分工 | 避免重复 |
| **P2** | 色板/按钮/对比度统一 | 完成度 |
| **P2** | 轻量音效与状态动效 | 游戏感 |

### 6.1 三十分钟验收循环（M6）

新档单 session 可完成：

**舰桥读推荐 → 星图 → 编队 → 战斗 → 采集 → 制造补缺 → 舰船/星港 → 回星图突破新节点**

每处缺口可一点跳转；每屏一个 Gold Primary。

### 6.2 实施波次（对应 [10](10-mvp-development-plan.md) P6）

| 波次 | 内容 |
| --- | --- |
| **Wave 0** | 分组导航、状态栏、ButtonRole、ShortageJump、任务抽屉 |
| **Wave 1** | 舰桥 → 星图 → 编队 → 战报 → 采集 → 制造 → 舰船 → 星港 |
| **Wave 2** | 招募、仓库/商店、角色卡牌分工 |
| **Wave 3** | 令牌/contrast/轻反馈 |

## 8. 无障碍与适配（P2 检查清单）

- 灰色小字对比度 ≥ WCAG 建议值（状态栏、锁定商品）
- 状态不仅靠颜色（加文字/图标）
- 按钮禁用须可读原因（Tooltip 或行内说明）
- 1920×1080 基线；缩放与键盘焦点在 Wave 3 回归
