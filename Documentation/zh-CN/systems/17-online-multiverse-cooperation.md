## 0. 先回答现状

### 0.1 当前如何「保证」多人体验？

**不能保证——因为 MVP 明确不做多人。**

| 层级 | 现状 |
| --- | --- |
| 运行模式 | 仅 **Solo** 可玩；`PlayMode.Online` 预留 |
| 玩家市场 | Solo **关闭**；无全服订单簿 |
| 星域/资源点 | 本地 `world.json`；无跨玩家占用 |
| 公会 / 合作远征 | 未实现 |
| 已有「多人友好」预备 | 领域规则可单测、`PlayMode` 门控市场、掉落/品质避免 SKU 爆炸 |

因此：多人体验的「保证」只能来自 **后续 Online 架构拍板**，不能靠当前客户端假装。

### 0.2 本文拍板意向（线上立项用）

采用用户提出的方向，并写成可落地的约束：

1. **每位舰长拥有自己的多元宇宙位面（Plane）**：同一批星域 Id / 资源点 Id，**互不抢占、无 PvP 冲突**；  
2. **玩家市场不设在位面内**，而设在跨位面的 **多元宇宙中转站（Hub）**；  
3. **不同位面物资产出偏置不同**，逼出贸易互补，而不是人人自给自足最优；  
4. 用 **断航余波压力**（熵雾、损耗、补给衰减）营造末日感，驱动 **公会互助**，但 **Solo 仍可独立通关首圈**。

## 1. 目标与非目标

### 1.1 目标

- 给 Online 一条清晰的社交经济骨架：**隔离探索 + 共享贸易 + 公会抗压**；  
- 避免传统 MMO「抢矿点 / 抢怪」带来的冲突与差体验；  
- 让合作成为**加速与抗压**手段，而非通关许可证；  
- 与现有 Solo 循环兼容（单向迁入或双轨，见 `14`）。

### 1.2 非目标

- MVP / Solo 必做内容  
- 开放世界实时同屏抢资源  
- 大型公会战争、领土占领战（可后置）  
- 用「必须组队」锁死主线  
- 与「多元宇宙 Boss 房」玩法混为一谈（名称相近，系统分离）

## 2. 术语

| 术语 | 定义 |
| --- | --- |
| **位面（Plane / ShardInstance）** | 绑定到账号（或小队）的平行宇宙实例；含完整星域进度与资源点状态 |
| **星域蓝图（Sector Blueprint）** | 所有位面共享的配置（区域图、遭遇、节点 Id）；实例状态各算各的 |
| **资源点实例** | 某位面内对 `gatherNodeId` / 刷取点的占用与产出；**不跨位面互斥** |
| **中转站（Nexus Hub）** | 跨位面公共空间；承载玩家市场、公会大厅、公告、部分社交 |
| **位面偏置（Plane Affinity）** | 该位面对某材料链的产量/品质/发现率修正 |
| **公会（Guild）** | Online 持久组织；共享订单、抗压 buff、有限互助额度 |
| **断航压力（Severance Pressure）** | 周期性/累积性环境惩罚，推动互助与贸易 |

## 3. 架构总览

```text
┌─────────────────────────────────────────────┐
│              Nexus Hub（中转站）              │
│  玩家市场 · 公会大厅 · 排行 · 公告 · 迁跃门   │
└───────────────┬─────────────────────────────┘
                │ 进出需账户在线 / 轻校验
     ┌──────────┼──────────┐
     ▼          ▼          ▼
 Plane-A     Plane-B     Plane-C
 (你的第七前沿) (他人的同构星域) ...
 区域/采集/挂机/制造 —— 全部位面本地结算
 资源点互不冲突
```

| 空间 | 权威 | 玩家交互 |
| --- | --- | --- |
| Plane | 服务端（建议）或强校验客户端+审计 | 几乎无直接冲突；可参观/援助需显式授权 |
| Hub | 服务端权威 | 市场撮合、公会、邮件/订单、有限聊天 |

**推荐默认：** 每位舰长 **1 个主位面**；公会可另开「协作远征位面」限时副本（后置），日常开发仍在私有位面。

## 4. 为何用多元宇宙位面（相对传统同服地图）

| 方案 | 优点 | 风险 |
| --- | --- | --- |
| 同服抢资源 | 竞争感强 | 堵门、抢点、新人挫败、客服成本 |
| **私有位面 + Hub 市场** | 探索节奏自控；内容复用；冲突为零 | 若无偏置与压力，易变成「单机联机皮」 |
| 仅排行榜无经济 | 实现便宜 | 合作动机弱 |

结论：**位面隔离解决冲突；偏置产量 + 压力 + Hub 市场解决「为何要遇见别人」。**

## 5. 位面偏置：强迫贸易互补

### 5.1 原则

- 每位面在创建时 roll 或由开拓局「航道相位」指定一组 **Affinity**；  
- 偏置作用于：**采集基础产量、刷取材料权重、加工副产物、稀有发现率**；  
- **不**把任何主线关键材料做成「某位面绝对为 0」（避免完全卡死）；  
- NPC 星港仍卖基础货，但价差大、限购紧 → 市场交易更优。

### 5.2 MVP-Online 建议偏置轴（对齐三链）

| Affinity | 加成 | 削弱（示例） |
| --- | --- | --- |
| `MetalRich` | 铁矿/废料/合金相关 +20%～40% | 生物纤维链 −15%～25% |
| `EnergyRich` | 晶砂/能量芯/线圈 +20%～40% | 金属板材 −15%～25% |
| `SynthRich` | 菌毯/生物纤维/合成网 +20%～40% | 能源芯 −15%～25% |
| `Balanced` | 全链 ±0～10% 小波动 | 无极端 |

玩家 UI 显示：「本相位航道 · 金属丰度高 / 合成贫瘠」——解释为何要挂单买纤维。

### 5.3 贸易动机公式（语义）

```text
自给速度 = f(本面偏置, 设施, 卡组)
市场加速 = 卖富余 × 买短缺
无市场时发展曲线明显慢于「互补交易」曲线（目标：中后期差 20%–40% 有效产能）
```

验收：在相同在线时长下，**参与 Hub 交易的样本**平均舰船门推进 / 三链成品数高于纯自给样本。

### 5.4 防刷

- 位面 Affinity **绑定账号**，迁移/重置有冷却与成本；  
- 小号批量 roll 神 Affinity：限制创建、设备/支付指纹、迁入冷却（见 `14`）；  
- 市场手续费 + 日交易额软顶；异常价告警。

## 6. 中转站市场（Hub Market）

### 6.1 位置与叙事

- 叙事：航网残骸上重建的 **多元宇宙中转站**——唯一仍能跨相位对齐的贸易锚点。  
- 玩法：离开位面进入 Hub（或位面内市场终端「上行链路」到 Hub）；**上架/撮合只在 Hub 权威区**。

### 6.2 与现有 `07` 对齐

| 项 | Online 方向 |
| --- | --- |
| 订单簿 | 全 Hub 共享（可先单服，后跨服合并需经济隔离） |
| 标的 | `(itemDefId, quality)`；卡牌规则仍按 `07` |
| Solo | 仍不可见玩家市场 |
| NPC | Hub 与位面内均可保留；价差引导玩家走订单簿 |

### 6.3 合作向功能（市场之上）

| 功能 | 作用 |
| --- | --- |
| 公会采购单 | 会长发「缺维修包 ×N」，成员可定向供货 |
| 互补推荐 | 根据双方 Affinity 推荐「你富余 ↔ 他短缺」 |
| 契约订单 | 限时交付换公会贡献 / 抗压点数 |

## 7. 末日压力：为何需要公会

目标情绪：**航网已毁，熵雾在涨，个人撑得了一时，撑不久。**  
手段必须 **可预期、可缓解、不毁档**。

### 7.1 压力条（建议组合，可分阶段上）

| 压力源 | 机制摘要 | 公会如何缓解 |
| --- | --- | --- |
| **熵雾潮汐** | 周期性提高全区战斗磨损 / 采集风险；短时抬高 Entropy 门槛 | 公会「屏障项目」降低本周公会成员潮汐强度 |
| **补给衰减** | 长期不贸易/不活动，NPC 限购更紧或维修材料消耗上浮 | 公会仓库调拨、集体采购 |
| **航道疲劳动摇** | Offline Cap / Yield Ratio 软衰减（可用活跃与互助重置） | 公会签到、互助任务恢复 |
| **断航余震事件** | 限时全服/全公会目标（修中转站、稳相位） | 贡献进度条；完成发绑定奖 |
| **个人耐久债** | 已有装备耐久循环（`06`）在 Online 略加强 | 公会维修订单、共享配方熟练提示 |

### 7.2 硬约束（防劝退）

1. **压力不删角色、不删舰、不清位面进度**；  
2. 最高惩罚形态：效率下降、风险上升、`PausedBlock` 类阻塞——与 Solo 精神一致；  
3. **不进公会仍可通关第七前沿首圈**；公会只影响「舒服度 / 速度 / 抗潮汐」；  
4. 压力数值进配置表；上线须有关闭开关与调参后台。

### 7.3 绝望感文案与 UX

- Hub 新闻：熵雾浓度、失联星区统计、中转站完好度；  
- 位面内：潮汐倒计时、贫瘠链「缺口警告」；  
- 避免纯数值大红字恐吓；强调「开拓局需要你们互相补给」。

## 8. 公会系统设计要点（Online）

| 模块 | MVP-Online 最小集 |
| --- | --- |
| 创建/加入 | 人数上限、冷却 |
| 公会仓库 | 材料进出权限；防盗日志 |
| 公会订单 | 内部要货 / 供货 |
| 抗压项目 | 消耗信用+材料，换本周潮汐减免 |
| 聊天/公告 | 文本即可 |
| 贡献 | 交付订单、捐仓库、活动分 |

后置：公会远征位面、公会 Boss、跨公会航网建设。

**合作激励排序（推荐）：** 贸易互补 > 公会仓库调拨 > 抗压项目 > 可选共同远征。  
避免一上来做大型战场。

## 9. 与 Solo / 迁入的关系

| 模式 | 位面 | Hub 市场 | 公会压力 |
| --- | --- | --- | --- |
| Solo | 本地单机「伪位面」 | 无 | 无（或极弱单机潮汐可选） |
| Online | 服务端 Plane | 有 | 有 |
| Solo→Online 迁入 | 新建 Online Plane，导入白名单进度 | 迁入后有交易冷却 | 迁入后若干日压力减免（新手缓冲） |

详见 `14-play-modes-and-persistence.md`。

## 10. 分阶段落地建议

| 阶段 | 交付 | 成功标准 |
| --- | --- | --- |
| M0 MVP Solo | 现状 | 不依赖本文 |
| O1 Online 骨架 | 账号、Plane 存档、Hub 空壳、玩家市场 | 可上架成交 |
| O2 偏置经济 | Affinity + NPC 价差 + 推荐 | 交易量与互补单占比上升 |
| O3 压力 v0 | 潮汐 + 公会抗压项目 | 公会留存 > 散人；投诉可控 |
| O4 公会经济 | 仓库 + 内部订单 | 公会成为中后期默认组织 |
| O5+ | 远征位面、航网共建、特殊玩法 | 另开专题 |

## 11. 开放问题（立项时再拍）

1. Affinity 是创建永久还是可花代价重组？  
2. Hub 是单服还是跨服合并经济？  
3. 公会人数与仓库税率？  
4. 压力是否对「日活很低的休耕号」自动休眠以免回流劝退？  
5. 「参观他人位面」是否开放（默认建议 **否**，降低实现与隐私成本）？

## 12. 验收口号（给制作人）

- **不冲突：** 同资源点 Id，不同位面可同时满产。  
- **要遇见：** 缺材时市场价明显优于硬扛 NPC。  
- **要抱团：** 潮汐周不进公会明显更肝/更疼，但不毁档。  
- **可单机：** 第七前沿首圈仍可 Solo 闭环。
