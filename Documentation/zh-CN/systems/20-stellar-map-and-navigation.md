## 1. 目标与非目标

### 1.1 目标

摆脱「关卡 1→2→3」式线性列表，让探索更像真实断航宇宙：

1. **舰船有位置**；雷达照亮局部，升级增大探索半径；  
2. **移动才揭示**：正常航行（星域内）与跃迁（星域间）；可输入坐标或随机航向；  
3. **星域 = 星球相对密集的团块**；进团块后更容易扫到星球；  
4. 找到 **中枢星球** 或向 NPC 购买 **星域海图**，解锁该星域已知坐标集；  
5. **星域间跃迁**默认消耗 **信标**（合成 / 任务 / NPC）；  
6. **移动消耗时间**（可离线推进），但须提供加速手段，禁止纯时间墙；  
7. **出生在宇宙边缘**（低危、低等级）；**越近宇宙中心**，遭遇与星球等级越高。

### 1.2 非目标

- 实时 3D 飞行操作、手操躲避（仍为卡牌挂机向）  
- 开放世界同屏抢点 PvP（Online 仍用位面，见 `17`）  
- 用航行完全取消区域战斗门槛（清剿 / 舰船门仍成立，见 `03`）  
- MVP 首发必须一次做完全宇宙图（见 §11 分阶段）

### 1.3 设计原则（趣味 / 真实）

| 原则 | 做法 |
| --- | --- |
| 信息有成本 | 雷达有限；海图/中枢是战略目标 |
| 选择有意义 | 坐标精确 vs 随机碰运气；航行 vs 耗信标跃迁 |
| 风险随深度 | 边缘安全、中心高危高报 |
| 不线性锁死 | 可绕行、可漏探、可先买图后清剿 |
| 不纯等待 | 航行可离线结算 + 材料/信用加速 |

## 2. 空间层级

```text
UniverseMap（宇宙图）
  └─ SectorCluster（星域团块）     ← 星球密度高的「盆地」
       └─ StellarBody（星球/异常点） ← 可登陆开发的点
            └─ RegionContent         ← 现有 Region：战斗/采集/刷取（03/11）
```

| 层级 | Id 示例 | 说明 |
| --- | --- | --- |
| 宇宙 | `universe_frontier` | 一张大坐标平面（或球面投影）；有边缘→中心难度梯度 |
| 星域 | `sector_frontier_vii` | 团块 AABB/半径；进入后探测权重提高 |
| 星球/点 | `body_outer_haven` | 坐标 `(x,y)`；绑定 0..N 个 `regionId` |
| 区域内容 | `sec01_outer_belt` | **玩法权威仍在 Region**；地图负责「如何找到并抵达」 |

**与现 MVP 对齐：** 第七前沿 6 个 `regionId` 落在同一星域团块内的若干星球上（可 1 星球多区域，或 1 区域 1 星球）。线性前置可保留为「推荐航线」，但 **物理上允许先扫到后区坐标**（开战仍受 `03` 硬门限制）。

## 3. 术语

| 术语 | 定义 |
| --- | --- |
| **舰船坐标** | `ship.x, ship.y`（宇宙平面单位）；存档权威 |
| **雷达范围** | 以舰船为圆心的揭示半径 `radarRange`；由扫描模块等决定 |
| **迷雾** | 未在雷达内且未海图解锁的坐标不可见或仅显示噪点 |
| **正常航行 Cruise** | 星域内（或同层短距）移动；耗时、耗微量能源；不耗信标 |
| **跃迁 Jump** | 跨星域（或超远距）瞬时/短时位移；**默认耗信标** |
| **信标 Beacon** | 跃迁消耗品 / 锚点道具 |
| **中枢星球 Hub Body** | 星域内特殊点；交互可解锁本星域海图 |
| **星域海图 Sector Chart** | 道具或状态：揭示该星域内全部（或高比例）星球坐标 |
| **危险等级 Threat Band** | 由距宇宙中心的径向距离映射；影响遭遇与掉落 |

## 4. 雷达与揭示

### 4.1 雷达模块

映射现有 `mod_scanner`（扫描阵列），可扩展专用 `mod_radar`：

| 模块等级 | `radarRange`（示意） | 附加 |
| ---: | ---: | --- |
| 0（裸船） | 8 | 仅紧邻 |
| 1 | 14 | 开局建议种子给 Lv.1 |
| 2 | 22 | 显示星球类型图标 |
| 3 | 32 | 弱提示「星域密度方向」 |
| 4+ | 40+ | 可标记异常信号 |

```text
visibleBodies = bodies where distance(ship, body) <= radarRange
             OR body.id ∈ unlockedByChart
             OR body.id ∈ manuallyBookmarked
```

### 4.2 探索手感

- 舰船**必须移动**才会把雷达圈带到新区；站桩不长出新星球。  
- 进入 **星域团块** 后：雷达内生成/刷新星球的权重 ×`sectorDensityBonus`（默认 2.0）。  
- 星域外虚空：多为熵雾噪声、稀有残骸事件，星球极少。

## 5. 移动：航行与跃迁

### 5.1 正常航行（Cruise）

| 项 | 规则 |
| --- | --- |
| 用途 | 星域内移动、贴边搜图、接近已知坐标 |
| 输入 | **坐标** `(x,y)` 或 **随机航向**（角度 + 距离档） |
| 耗时 | `time = distance / cruiseSpeed`；`cruiseSpeed` 受推进模块影响 |
| 消耗 | 能源（或「航行燃料」材料）；不足则无法启动 |
| 过程 | 卡组可继续挂机；舰船状态 `InTransit`；到达后结算揭示 |

随机航向：适合「盲搜」；可配置短/中/长三段距离，长距遇熵雾事件概率更高。

### 5.2 跃迁（Jump）

| 项 | 规则 |
| --- | --- |
| 用途 | **星域间**或超远距点对点 |
| 前提 | 持有并消耗 **信标**（默认 1）；目标坐标已知 **或** 盲跃（高风险） |
| 耗时 | 短于等价航行（如 10%～30% 航行时间），体现航网残片捷径 |
| 盲跃 | 无精确坐标时按方向+距离；可能偏航、遇强敌、耗额外信标 |

### 5.3 坐标输入 UX

```text
[航行] 输入 X,Y → 预览距离/时间/燃料 → 确认
[航行] 随机：转盘选方向 + 距离档
[跃迁] 选择已解锁星域锚点 / 粘贴坐标 + 信标预览
```

已知坐标来源：雷达扫到、海图、任务标记、NPC、玩家书签。

## 6. 星域、中枢与海图

### 6.1 星域团块

| 字段 | 含义 |
| --- | --- |
| `sectorId` | 如 `sector_frontier_vii` |
| `center, radius` | 团块几何 |
| `threatBand` | 该团块基准危险带 |
| `hubBodyId` | 中枢星球 |
| `chartItemId` | 对应海图道具 |

进入半径内：UI 提示「已进入某某星域引力井」；探测权重提升。

### 6.2 解锁全星域坐标的两种主路径

| 路径 | 玩法 |
| --- | --- |
| **中枢** | 抵达并交互中枢（可要求小战斗/对话）→ `UnlockSectorChart(sectorId)` |
| **NPC 购图** | 星港/游商出售 `chart_sector_*`；价高但省探索时间 |
| （辅） | 任务奖励局部坐标包；扫描满探索度百分比解锁 |

解锁后：该星域内星球在地图上常亮（不受雷达限制），但仍需 **航行抵达** 才能登陆开战。

### 6.3 与 Region 战斗的关系

```text
地图抵达 body
  → 打开该点 Region 列表
  → CanEnter(region) 仍用 03：前置通关 + 舰船门
  → 通过后刷取/采集挂钩不变
```

即：**找路靠空间探索；开打仍靠战力与舰船建设**——两条成长轴都有意义。

## 7. 信标（Beacon）

| 项 | MVP 方向 |
| --- | --- |
| 道具例 | `con_jump_beacon`（消耗品）；高阶 `con_beacon_stable`（降低偏航） |
| 来源 | 合成（能源链/合成舱）、任务、NPC、刷取低概率 |
| 消耗 | 标准跃迁 1 个；跨高危带或超远距可 2 |
| 常驻锚 | 可选「部署信标」把坐标写成可反复跃迁的锚点（另耗 1 + 建造时间） |

经济上：信标是 **跨星域扩张的阀门**，避免玩家瞬间跳到中心高危区。

## 8. 航行时间与反时间墙

| 规则 | 说明 |
| --- | --- |
| 航行/跃迁耗时 | 写入 `TransitAction`；占用可选「驾驶编制」或仅锁舰船不锁全部卡组 |
| 离线 | 计入离线结算：`credited` 时间推进航程（与 `04` 同一时钟） |
| 加速 | 材料加速 / 信用跳过短途；长途禁止「唯一只能挂机等」 |
| 并行 | 航行中允许已启动的采集/制造继续（舰船移动 ≠ 全员停工） |

硬约束继承 `03`：舰船成长与推进 **不得**仅靠等待解锁下一内容。

## 9. 边缘出生与中心难度

### 9.1 径向难度

```text
r = distance(shipOrBody, universeCenter)
threatBand = f(r)   // 边缘低，中心高
```

| 带 | 位置 | 星球/遭遇等级感 | 玩家阶段 |
| --- | --- | --- | --- |
| Edge | 外缘 | Lv 低、资源基础 | 开局第七前沿 |
| Mid | 中间带 | 中等熵雾与掉落 | 多星域 |
| Core | 近中心 | 高等级、强 Boss、稀有航网残骸 | 后期 |

### 9.2 开局

- 出生点：宇宙边缘某安全锚（叙事：开拓局投放舱）。  
- 初始星域：`sector_frontier_vii` 落在 Edge 带。  
- 开局雷达短、无跨域信标或仅给 1～2 枚教学信标。  
- 中心坐标初期 **不显示** 或显示为「高熵禁区（数据不足）」。

## 10. 随机事件与探索趣味（轻量）

航行途中按距离/危险带 roll：

| 事件 | 效果 |
| --- | --- |
| 熵雾湍流 | 偏航、耗时 +、小幅耐久 |
| 残骸信号 | 获得废料/坐标碎片 |
| 商船 | 临时 NPC 货架（高价海图页） |
| 遭遇伏击 | 可自动战斗或逃离（逃离耗燃料） |
| 废弃信标 | 获得信标或解锁远距锚点 |

保持低操作：弹窗选择「接战 / 规避 / 打捞」，结算后继续航线。

## 12. 数据模型（草案）

```text
UniverseConfig
- center, edgeRadius
- threatBands[]

SectorCluster
- sectorId, center, radius, hubBodyId, chartItemId, threatBand

StellarBody
- bodyId, sectorId, x, y, displayName
- regionIds[]
- bodyType: Planet|Station|Anomaly|Hub

ShipNavigationState
- x, y
- radarRange          // 由模块推导可缓存
- unlockedCharts[]    // sectorId
- knownBodyIds[]
- transit?: { mode: Cruise|Jump, destX, destY, finishesAtUtc, beaconCost }

Beacon / Chart → ItemDef（09）
```

服务：`NavigationService.TryCruise` / `TryJump` / `TickTransit` / `RevealRadar`。

## 14. 验收口号

- **不是点下一关**，而是 **把船开过去**。  
- **雷达决定看见什么**，**海图决定少走弯路**，**信标决定何时换星域**。  
- **边缘养号，中心发财也要命**。  
- **航行要花时间，但绝不只能干等**。
