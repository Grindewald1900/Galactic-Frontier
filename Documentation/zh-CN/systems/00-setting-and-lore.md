## 1. 目标与非目标

### 1.1 目标

为本游戏锁定**可对外讲述的简化世界观**，并映射到已有玩法：

- 解释为何要开图、升舰、扛熵雾、采集制造、使用市场；  
- 定义玩家身份、开局资产与长期志向；  
- 为 UI 文案、新手引导、星域叙事提供统一用语。

### 1.2 非目标

- 完整小说、多结局分支、过场动画脚本（可后置）  
- 断航灾变「真相」的最终揭晓（仅作长期悬念钩子）  
- 改变已拍板的系统规则（占用、品质、Solo 无玩家市场等）  
- 第二星域 / 多领主争霸玩法细则（长期目标，非 MVP；空间地图见 `20`）

## 2. 一句话定位

> 断航三百年后，你作为**群星开拓局**新晋舰长，驾驭一艘小型开拓舰，在熵雾撕裂的边境星区重建航道、贸易与前哨——并慢慢逼近那场灾变的真相。

玩法侧一句话（不变）：战斗开图 → 挂机采集/刷取 → 加工制造 → NPC 经济 /（线上）市场 → 卡组与舰船成长。

## 3. 纪元故事（简化定稿）

### 3.1 群星断航

三百年前，人类与其他星际文明共同建设了连接诸星系的巨大航行网络——**群星航网**。

航网曾经能够：

| 航网职能 | 叙事含义 | 玩法映射 |
| --- | --- | --- |
| 稳定星际航道 | 远距离安全航行 | 区域推进、航行距离（Range） |
| 为殖民地供电 | 能源调配 | 能源模块 / 高耗能区门槛（Energy） |
| 维持远距通信 | 情报与协调 | 扫描 / 揭示（Scan）；后续情报玩法钩子 |
| 抵御宇宙异常 | 压制空间紊乱 | **熵雾抗性**（EntropyResist） |
| 支撑跨文明贸易 | 物资与卡牌流通 | 市场终端；Solo=NPC，Online=玩家市场 |

一场被称为 **断航灾变** 的事故摧毁了航网核心。

此后：

- 无数星球与外界失联；  
- 航道被 **熵雾** 覆盖——一种异常空间；  
- 闯入熵雾的舰船可能迷失、遭遇失控机械、变异生物，以及旧战争留下的残影；  
- 星际文明分裂为大量**孤立星区**。

### 3.2 重启航网

灾变三百年后，各文明联合成立：

> **群星开拓局**（Frontier Expansion Bureau）

开拓局负责：

- 招募舰长；  
- 探索失联星区；  
- 建设前哨站；  
- 恢复星际贸易；  
- （长期）调查断航灾变的真正原因。

玩家是一名**刚获得开拓许可证**的开拓舰长，被派往边境试验星域之一：**群星边境 · 第七前沿**（`sector_frontier_vii`）。

## 4. 玩家身份与开局资产

### 4.1 身份

| 项 | 定稿 |
| --- | --- |
| 称谓 | 开拓舰长（Pioneer Captain） |
| 隶属 | 群星开拓局 |
| 凭证 | 开拓许可证（新晋） |
| MVP 舞台 | 第七前沿（1 星域 × 6 区域） |
| 长期志向 | 从边境舰长成长为控制多星区的**开拓领主**；查清断航真相 |

### 4.2 开局仅有（与种子/系统对齐）

| 叙事表述 | 系统落点 |
| --- | --- |
| 一艘小型开拓舰 | 账号唯一主舰；Level 1 + 基础模块（`ShipService` / `03`） |
| 一支基础战斗队 | 开局可战斗角色 + 编队卡组（Formation / Deck） |
| 一套简易资源采集设备 | 采集行动 + 外缘/矿脉节点（Gather / `09`/`11`） |
| 一个连接公共交易网络的市场终端 | Market 屏：MVP **Solo 仅 NPC 星港**；Online 再开玩家市场（`07`） |

说明（避免与经济文档冲突）：

- 「公共交易网络」在叙事上是航网残骸上重建的商务链路；  
- **MVP 单机**中，终端只能连到开拓局认证的 **NPC 商人**；  
- **线上模式**才恢复舰长之间的全服订单市场——对应「贸易重启」的下一阶段。

### 4.3 开局不做的事

- 不要求玩家理解断航真相；  
- 不强制多星区领主玩法；  
- 不把公会/多人合作当作首圈前提。

## 6. 与玩法系统的映射

| 玩法 | 故事解释 |
| --- | --- |
| 区域双重门槛（战斗+舰船） | 航道未稳：既要清威胁，也要舰体扛住熵雾与航程 |
| 熵雾抗性模块 | 航网「抵御异常」职能的民用化残骸技术 |
| 挂机刷取 / 采集 | 前哨周边清残敌、回收航材与矿藏 |
| 加工 / 制造 / 品质 | 在补给断绝的边境自建产线 |
| 装备耐久与维修 | 熵雾与高强度行动持续磨损设备 |
| 多卡组占用 | 人手有限的开拓编制；一人不能同时在多条任务线上 |
| NPC 商店 | 开拓局/星港认证商人，维持最低贸易 |
| 玩家市场（Online） | 航贸在 **多元宇宙中转站** 恢复后的舰长间交易（位面内不抢点） |
| 多元宇宙位面（Online） | 断航导致相位分裂：同构星域可平行开发、互不冲突 |
| 虫洞 / 暗面 / 多元宇宙 Boss 房（后置） | 航网破裂后的危险捷径与挑战层（≠ 日常位面系统） |

## 7. MVP 叙事范围

### 7.1 必须传达（文案/引导）

1. 断航与熵雾导致星区孤立；  
2. 玩家是开拓局新舰长；  
3. 当前任务是开发 **第七前沿**（通关 6 区并击败边境锚点首领）；  
4. 通过战斗、采集、制造与星港贸易自我补给。

### 7.2 MVP 可轻描、不展开

- 断航灾变元凶；  
- 其他文明细节；  
- 开拓领主制度与多星区统治；  
- 航网完全重建。

### 7.3 区域叙事挂钩（第七前沿）

在 `11-sector-and-region-content.md` 的区域主题上统一口吻：

| 区域 | 故事钩子（一句） |
| --- | --- |
| 外缘带 | 许可证后的第一站：清理航道残骸，证明你能活下来 |
| 矿脉支线 | 失联矿带，回收航材与双链原料 |
| 量子裂隙 | 熵雾渗漏严重，需能源与抗性模块才能深入 |
| 深渊边界 | 灾变残影与高压战场，维修成为日常 |
| 护航航道 | 尝试恢复后勤线，为总攻集结补给 |
| 边境锚点 | 本星域威胁核心；清除后第七前沿首圈宣告收复 |

星域一句话（替换旧「殖民航线外缘」表述）：

> 第七前沿是开拓局在断航带边缘设立的试验星域：收复它，就等于在熵雾中钉下一颗新的航路钉子。
