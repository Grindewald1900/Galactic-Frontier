## 1. 目标与非目标

### 1.1 目标

为本游戏锁定**可对外讲述的简化世界观**，并映射到已有玩法：

- 解释为何要开图、升舰、扛熵雾、采集制造、使用市场；  
- 定义玩家身份、开局资产与长期志向；  
- 为 UI 文案、新手引导、星域叙事提供统一用语；  
- 让每个区域在叙事上回答：**「这里威胁什么 → 该造什么 → 再回来验证」**。

### 1.2 非目标

- 完整小说、多结局分支、过场动画脚本（可后置）  
- 断航灾变「真相」的最终揭晓（仅作长期悬念钩子）  
- 在本文件内重写已拍板的系统数值（占用、品质、Solo 无玩家市场等）  
- 第二星域 / 多领主争霸玩法细则（长期目标，非 MVP）

### 1.3 设定层验证四问（文案与任务设计时自检）

| 字段 | 本设定的回答 |
| --- | --- |
| **玩家问题** | 断航后，我凭什么在熵雾里活下来并往前推进？ |
| **关键决策** | 有限舰员派去战斗、采集还是制造？为当前区域威胁造什么装备？接哪张开拓局订单？ |
| **失败风险** | 若只剩「战力不够」而无「威胁—解法」因果，或频繁拆队搬人，故事与玩法都会变成管理负担 |
| **验证指标** | 玩家能否说清「这一区怕什么、我造了什么、再战为何变好」 |

## 2. 一句话定位

### 2.1 世界观

> 断航三百年后，你作为**群星开拓局**新晋舰长，从宇宙边缘向中心推进：在熵雾撕裂的星域中**扩建舰队**、**驻扎已收复星球**、突破**卡关航道**，并随探索度解锁主星、阵营商店与深空异象。

### 2.2 产品承诺（玩法侧）

> **用有限的舰员同时经营多条任务线，生产针对性装备，突破新的星域威胁。**

三系统分工（叙事与 UI 须一致）：

| 系统 | 职责 | 玩家感受 |
| --- | --- | --- |
| **战斗** | **提出问题** — 这一区的主要威胁是什么？ | 「我为什么打不过 / 打得吃力？」 |
| **生产** | **提供解法** — 针对性装备、模块、耗材 | 「我造了这东西，就是为了下一场。」 |
| **编制占用** | **制造取舍** — 人手不能同时铺满所有线 | 「先保战斗队，还是停采集去赶工？」 |

玩法链：向中心探索 → 战斗开图（含卡关区）→ 驻扎/挂机采集 → 加工制造 → NPC 经济 → **舰队与卡牌**成长。

## 3. 向宇宙中心推进（非线性）

### 3.0 难度与卡关（概要）

| 概念 | 定稿 |
| --- | --- |
| 难度曲线 | **非线性**；距宇宙中心总体趋难，但存在**缓坡区**与**卡关区（Gate）** |
| 卡关区 | 难度陡升；需特定构筑/舰船/装备；通关后产出**稀有物资**（卡牌能级、舰船模块、稀有图纸） |
| 绕路 | 可先探索侧翼星球积累资源，再攻坚卡关（见 `20` 地图） |

第七前沿试点：`量子裂隙`、`深渊边界` 为 Gate；`边境锚点` 为 Boss Gate。细则与掉落 → **`21` §2**。

## 4. 纪元故事（简化定稿）

### 4.1 群星断航

三百年前，人类与其他星际文明共同建设了连接诸星系的巨大航行网络——**群星航网**。

航网曾经能够：

| 航网职能 | 叙事含义 | 玩法映射 |
| --- | --- | --- |
| 稳定星际航道 | 远距离安全航行 | 区域推进、航行距离（Range） |
| 为殖民地供电 | 能源调配 | 能源模块 / 高耗能区门槛（Energy） |
| 维持远距通信 | 情报与协调 | 扫描 / 揭示（Scan）；后续情报玩法钩子 |
| 抵御宇宙异常 | 压制空间紊乱 | **熵雾抗性**（EntropyResist） |
| 支撑跨文明贸易 | 物资与卡牌流通 | 市场终端；Solo=NPC，Online=玩家市场 |

一场被称为 **断航灾变** 的事故摧毁了航网核心。

此后：

- 无数星球与外界失联；  
- 航道被 **熵雾** 覆盖——一种异常空间；  
- 闯入熵雾的舰船可能迷失、遭遇失控机械、变异生物，以及旧战争留下的残影；  
- 星际文明分裂为大量**孤立星区**。

### 4.2 重启航网

灾变三百年后，各文明联合成立：

> **群星开拓局**（Frontier Expansion Bureau）

开拓局负责：

- 招募舰长；  
- 探索失联星区；  
- 建设前哨站；  
- 恢复星际贸易；  
- 发布**开拓局订单**（见 §5），把分散前哨的需求汇总成可执行目标；  
- （长期）调查断航灾变的真正原因。

玩家是一名**刚获得开拓许可证**的开拓舰长，被派往边境试验星域之一：**群星边境 · 第七前沿**（`sector_frontier_vii`）。

## 5. 玩家身份与开局资产

### 5.1 身份

| 项 | 定稿 |
| --- | --- |
| 称谓 | 开拓舰长（Pioneer Captain） |
| 隶属 | 群星开拓局 |
| 凭证 | 开拓许可证（新晋） |
| MVP 舞台 | 第七前沿（1 星域 × 6 区域） |
| 长期志向 | 从边境舰长成长为控制多星区的**开拓领主**；查清断航真相 |

### 5.2 开局仅有（与种子/系统对齐）

| 叙事表述 | 系统落点 |
| --- | --- |
| 一艘小型开拓舰 + **基础图纸包** | 首舰 + 1–3 张基础船型图（`21`）；现 MVP 可先单主舰 |
| 一支基础战斗队 | 绑定首舰的 5 人 `DeckEntity` |
| 一套简易资源采集设备 | 采集行动 + 外缘/矿脉节点（Gather / `09`/`11`） |
| 一个连接公共交易网络的市场终端 | Market 屏：MVP **Solo 仅 NPC 星港**；Online 再开玩家市场（`07`） |

说明（避免与经济文档冲突）：

- 「公共交易网络」在叙事上是航网残骸上重建的商务链路；  
- **MVP 单机**中，终端只能连到开拓局认证的 **NPC 商人**；  
- **线上模式**才恢复舰长之间的全服订单市场——对应「贸易重启」的下一阶段。

### 5.3 舰队与编制（概要 → `21` 全文）

| 概念 | 定稿 |
| --- | --- |
| **舰队** | 玩家拥有多艘舰船；**每舰绑定 1 个 5 人编队** |
| **扩编** | 新建舰船 = 新编队槽；需**图纸 + 材料 + 港口工位** |
| **图纸** | 新手附赠基础型；稀有图来自卡关/秘境/NPC；Online 可玩家市场 |
| **舰船增幅** | 绑定编队在战斗/采集时获得舰船属性加成 |
| **舰船被动** | 每型船 1 个主被动（战斗/采集/均衡）；自动触发 |
| **驻扎** | **已通关星球**可派舰船常驻采集（占舰占队） |
| **探索度** | 在星域内航行越久，发现新星球的概率越高；50% 主星+阵营商店，100% 常规 Boss，>100% 异象事件 |

现 MVP 代码可为「单主舰 + 多卡组」；叙事与长期目标以舰队模型为准（见 `21` §8 迁移）。

### 5.4 开拓编制用语（叙事层）

开拓局标准编制分两层，用于解释「为什么人手有限」：

| 编制类型 | 叙事 | 玩法映射（当前实现） |
| --- | --- | --- |
| **前线战队** | 5 人完整编队；驻舰出征 | 绑定 `ShipInstance` 的 `DeckEntity` |
| **驻扎舰队** | 已清除星球轨道上的常驻采集/低强度刷取 | `Stationed` 状态 |

文案统一：**「舰员」** 既是战斗单位，也是生产体系中的稀缺编制；禁止写成「无限克隆人口」。

### 5.5 开局不做的事

- 不要求玩家理解断航真相；  
- 不强制多星区领主玩法；  
- 不把公会/多人合作当作首圈前提。

## 6. 开拓局订单（单机需求侧叙事）

固定 NPC 商店解决「清库存」，但**生产动机**来自开拓局向前哨发布的**订单（Bureau Orders）**。

### 6.1 设定

| 项 | 定稿 |
| --- | --- |
| 发布方 | 群星开拓局第七前沿调度席 |
| 形式 | 定期挂出的材料/装备需求清单；与当前区域危机挂钩 |
| 奖励 | 信用点、模块蓝图、区域情报、有时效的前哨加成 |
| 玩家选择 | 同时可见 **2–3 张可选订单**，非机械交货单 |
| 品质 | 高品质交付有额外奖励；叙事上为「前哨急需可靠货」 |

### 6.2 示例（叙事模板）

> **订单：裂隙前哨稳定剂**  
> 需求：能芯单元 ×3（品质 ≥ Q3）  
> 背景：量子裂隙观测站报告相位漂移加剧。  
> 奖励：信用点 + 「熵雾扫描数据」情报（解锁下一区提示）  
> 完成台词：「调度席确认：前哨读数回稳。你可以申请深入裂隙航道。」

### 6.3 与系统映射

| 状态 | 说明 |
| --- | --- |
| **叙事权威** | 本文 + `10` 任务链扩展 + `11` 区域危机句 |
| **MVP 实现** | 可先由 **Missions 步骤奖励 / 区域 FirstClear** 扮演「订单完成」；独立 `BureauOrderService` 为 P1 体验增强，非阻塞 Solo 闭环 |
| **Online 迁移** | 订单池可升级为 Hub 公共委托或玩家接单（见 `17`） |

## 7. 区域威胁与制造解法（第七前沿）

每个可探索区域除舰船门外，须在叙事与任务上呈现 **「威胁 → 观察 → 制造解法 → 再战验证」**。  
数值与物品 Id 以 `11-sector-and-region-content.md`、`09-resources-and-warehouse.md` 为准；下表锁**因果语义**。

| 区域 | 威胁（玩家可观察） | 叙事问题 | 推荐制造/装备解法 | 对应物品方向（示例） |
| --- | --- | --- | --- | --- |
| **外缘带** | 巡逻火力穿甲；前排易崩 | 「护甲不够」 | 基础护甲板、前排模块 | `equip_hull_plate`、维修包 |
| **矿脉支线** | 矿脉高热环境；持续灼损 | 「每回合在掉血」 | 冷却装备、耐热外勤装 | 合成链冷却/防护向成品 |
| **量子裂隙** | 熵雾干扰；技能常失手 | 「命中率被熵雾吃掉」 | 扫描/相位稳定模块 | 能源链模块；**Gate 稀有：相位核心** |
| **深渊边界** | 重甲封锁体；维修压力 | 「打不动 / 装备在碎」 | 穿甲武器、强化维修耗材 | 金属链穿甲；**Gate 稀有：航网残片** |
| **护航航道** | 孢子与生物污染；长期中毒 | 「状态拖垮续航」 | 净化耗材、生命维持升级 | 合成链消耗品；LifeSupport |
| **边境锚点** | 复合威胁；锚点核心 | 「前面所有问题叠在一起」 | 综合构筑 + 满编战队 | 多链成品；Boss 战前检查清单 |

**禁止**把推进动机写成单纯「舰船 Lv.3 解锁」——门控可以存在，但 UI 与任务须同时告诉玩家**威胁与对策**。

战报叙事（全自动战斗的「产品面孔」）应帮助玩家回答：

- 为什么输了 / 为什么险胜；  
- 哪个敌人威胁最大；  
- 换装备、站位或策略后**可能**改善什么。

示例（文案模板，非最终 UI）：

> 前排在第 4 回合崩溃；敌方穿甲单位造成总伤害 47%。建议：提高前排护甲，或制造穿甲模块后更换武器配置。

## 9. 与玩法系统的映射

| 玩法 | 故事解释 |
| --- | --- |
| 区域双重门槛（战斗+舰船） | 航道未稳：既要清威胁，也要舰体扛住熵雾与航程 |
| 区域威胁—制造解法 | 熵雾带不是「更高数字」，而是需要**对的装备** |
| 熵雾抗性模块 | 航网「抵御异常」职能的民用化残骸技术 |
| 挂机刷取 / 采集 | 前哨周边清残敌、回收航材与矿藏 |
| 加工 / 制造 / 品质 | 在补给断绝的边境自建产线；高品质供订单与前哨 |
| 装备耐久与维修 | 熵雾与高强度行动持续磨损设备 |
| 多卡组占用 | 人手有限的开拓编制；一人不能同时在多条任务线上 |
| NPC 商店 | 开拓局/星港认证商人，维持最低贸易 |
| 卡关区稀有掉落 | 通关陡区后回收相位核心等，升级卡牌能级/舰船 |
| 舰队一舰一队 | 造舰扩并行；图纸驱动 |
| 驻扎采集 | Cleared 星球轨道常驻产线 |
| 星域探索度 | 航行越久，发现新星越高；分段解锁主星/Boss/异象 |
| 开拓局订单 | 把「该造什么」变成有叙事的目标（§6） |
| 玩家市场（Online） | 航贸在 **多元宇宙中转站** 恢复后的舰长间交易 |
| 多元宇宙位面（Online） | 断航导致相位分裂：同构星域可平行开发、互不冲突 |
| 虫洞 / 暗面 / 多元宇宙 Boss 房（后置） | 航网破裂后的危险捷径与挑战层 |

## 10. MVP 叙事范围

### 10.1 必须传达

1. 断航与熵雾导致星区孤立；  
2. 玩家是开拓局新舰长；  
3. 当前任务是开发 **第七前沿**（通关 6 区并击败边境锚点首领）；  
4. 通过战斗发现问题、制造解法、编制取舍，完成前哨订单与星港贸易。

5. 向中心推进会遇到**卡关区**，通关后可采稀有物资强化卡牌与舰船；  
6. **舰队**扩编、**驻扎**与**探索度**解锁主星与深空事件（可渐进实装）。

### 10.2 MVP 可轻描、不展开

- 断航灾变元凶；  
- 其他文明细节；  
- 开拓领主制度与多星区统治；  
- 航网完全重建。

### 10.3 区域叙事挂钩（第七前沿）

| 区域 | 故事钩子（一句） | 威胁关键词 |
| --- | --- | --- |
| 外缘带 | 许可证后的第一站：巡逻队教你「护甲」两个字 | 穿甲、前排 |

## 11. 新手故事弧（目标体验，给 `10` / UI）

当前实现为 **5 步系统教学链**（编队→首战→采集→制造→星港）。  
**设定目标**是在不破坏 Solo 约束的前提下，让玩家完成一次**策略闭环**：

| 顺序 | 叙事节拍 | 玩家行为 | 验证点 |
| --- | --- | --- | --- |
| 1 | 编成首支战队 | Formation | 5 分钟内可开战 |
| 2 | 首战**失败或惨胜** | Explore → Battle | 15 分钟内理解「护甲/威胁」 |
| 3 | 启动采集 | Gather | 为制造备料 |
| 4 | 制造针对性装备 | Crafting | 30 分钟内完成「采集—制造」 |
| 5 | 调整站位/装备再战 | Explore → Battle | 明显改善（非纯数值碾压文案） |
| 6 | 解锁前哨挂机 | AutoCombat | 感受「通关后的运营」 |
| 7 | 接到下一张开拓局订单 | Missions / 订单 UI | 指向下一区域危机 |

链完成文案（保留）：「新手航线完成——开拓局确认你具备独立作业资格。」

**两小时**指玩家已能**自主重复**「威胁→制造→再战→订单」循环的时间，而非纯教程长度。
