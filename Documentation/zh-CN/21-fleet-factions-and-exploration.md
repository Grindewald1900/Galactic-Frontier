## 1. 目标与非目标

### 1.1 目标

在「向宇宙中心推进」的长期框架下（玩法上是**编织航网**，见 `20`），锁定五块设定与规则语义：

1. **非线性难度与卡关区** — 难度非纯线性；存在陡升「卡关」节点，通关后产出稀有物资供**卡牌能级 / 舰船**升级；  
2. **舰队编制** — 一舰一编队；扩并行须**造新舰**；造舰需**图纸**；舰船提供属性增幅与**被动技能**（战斗/采集）；  
3. **驻扎采集** — 已通关星球可派遣舰队驻扎，持续采集；  
4. **宇宙阵营与关卡敌方阵容** — 阵营世界观 + 各区域/遭遇的敌方编制语义；  
5. **星域探索度** — 在星域内航行越久，发现新星球的概率越高；分段解锁主星、阵营商店、Boss、超探索事件。

### 1.2 非目标

- 在本文件写死全部数值（概率、秒数、蓝图价格进配置表）  
- 取消现 MVP 已落地的「单主舰 + 多卡组」实现（见 §12 迁移）  
- 一次实装全宇宙多星域（首包仍可从第七前沿试点）

## 2. 向宇宙中心：非线性难度与卡关区

### 2.1 空间难度梯度（叙事 + 规则）

| 概念 | 定稿 |
| --- | --- |
| **宇宙边缘** | 出生/新手区；威胁低、资源基础、教学友好；Online 为不同**边缘扇区**（`20` §7） |
| **径向深度 / 环带** | 外缘→开拓→断航→位面→内环→中枢；环带内网状，不是固定章节墙 |
| **推荐远征等级** | 软门：可越级，但熵雾/禁自动返航等代价上升（`20` §4） |
| **五维难度** | 敌人、熵雾、距离、情报、资源共同提高；**不是**每前进一步只加 HP |
| **卡关区（Gate Region / Choke Body）** | 难度**陡升**的节点；常同时要求战斗构筑 + 舰船分项 + 特定解法装备 |
| **绕路** | 允许先走工业/商贸/裂隙侧翼积累，再回头攻坚卡关 |

### 2.2 卡关区特征

| 项 | 规则语义 |
| --- | --- |
| 识别 | UI 标记「航道卡口 / Gate」；任务与开拓局订单提示「建议携带××模块」 |
| 失败体验 | 战报须说明机制原因（非仅战力数字） |
| 通关奖励 | **稀有物资**（见下表），显著高于普通区 |
| 重复收益 | 可刷取，但稀有掉落权重低于首通 |

### 2.3 卡关稀有物资用途

| 物资类型 | 叙事 | 玩法挂钩 |
| --- | --- | --- |
| **相位核心（Phase Core）** | 熵雾中凝结的稳定相位 | 卡牌**能级**突破材料（`19`） |
| **航网残片（Grid Fragment）** | 古代航网导体碎片 | 舰船**模块**升级 / 蓝图进阶 |
| **卡口蓝图轴（Gate Schema）** | 卡关设施拆解图 | **稀有舰船图纸**或专属模块 |
| **异种标本（Xeno Specimen）** | 中心区生物/机械样本 | 高级制造保底、阵营商店兑换 |

第七前沿试点卡关（与现有区域对齐，可 1–2 个标 Gate）：

| 区域 | 是否 Gate | 卡关机制（叙事） | 首通稀有掉落方向 |
| --- | --- | --- | --- |
| 量子裂隙 | **是** | 命中/相位；无稳定模块难通过 | 相位核心、扫描模块蓝图 |
| 深渊边界 | **是** | 重甲 + 耐久消耗双压 | 航网残片、穿甲蓝图轴 |
| 边境锚点 | Boss Gate | 复合机制 | 三类稀有 + 首领专属蓝图 |

外缘带 / 矿脉 / 护航航道为**缓坡区**，不构成硬 Gate。

## 3. 舰队：一舰一编队

### 3.1 核心语义

```text
玩家账号
  └─ Fleet（舰队）
       └─ ShipInstance × N
            ├─ 绑定 1 个 DeckEntity（5 人编制，独占）
            ├─ ShipBlueprint 定义船型
            ├─ 舰船属性 → 增幅绑定卡组
            ├─ 舰船被动（战斗型 / 采集型 / 均衡型）
            └─ 状态：Idle / InTransit / Combat / Gather / Stationed / ...
```

| 决议 | 说明 |
| --- | --- |
| **一舰一编队** | 每艘舰最多绑定 **1** 套 5 人 `DeckEntity`；扩并行 = **造舰**，而非无限卡组槽 |
| 舰员占用 | 编制占用规则不变：Running 中角色不可借调 |
| 主舰 | 首艘为**开拓舰**（许可证附带）；其余为舰队成员 |
| 并行上限 | `min(已造舰船数, 港口泊位, 许可等级)` |

### 3.2 舰船图纸（Blueprint）

| 来源 | 船型示例 | MVP / 后期 |
| --- | --- | --- |
| **新手附赠** | 开拓舰（均衡）、工勘艇（采集向）、突击护卫舰（战斗向） | 首包 1–3 张基础图 |
| **卡关 / 秘境** | 相位巡洋舰、重型货驳、熵雾拦截舰 | 稀有；带专属被动 |
| **NPC 商店 / 行商** | 轮换图纸、模块轴 | Solo 主来源 |
| **阵营商店** | 阵营特色舰（见 §5） | 探索度 ≥50% 解锁 |
| **玩家市场** | 二手图纸、成品舰合同 | **Online only** |

建造流程（语义）：

```text
持有 Blueprint + 材料 + 港口工位 → 建造队列 → ShipInstance 入港
  → 绑定或新建 DeckEntity → 可出征 / 驻扎
```

### 3.3 舰船属性与被动

| 类别 | 作用对象 | 示例 |
| --- | --- | --- |
| **Hull / Range / Energy / EntropyResist / Cargo / Scan / LifeSupport** | 区域门 + 航行 | 与现 `ShipEntity.stats` 对齐 |
| **战斗增幅** | 绑定卡组全体 | 「炮击阵列」：物理伤 +8%；「相位屏」：命中 +5% |
| **采集增幅** | 绑定卡组采集行动 | 「矿脉共振」：采集周期产出 +12% |
| **舰船被动技能** | 自动触发（无手操） | 见 §3.4 |

增幅在**绑定 deck 出战/采集/驻扎**时生效；未绑定 deck 的闲置舰仅提供港口仓储等静态加成（可选）。

### 3.4 舰船被动技能（示例池）

| passiveId | 中文 | 类型 | 效果语义 |
| --- | --- | --- | --- |
| `passive_broadside` | 舷炮齐射 | 战斗 | 每 3 回合，对敌方前排造成舰船火力 × 系数伤害 |
| `passive_phase_cloak` | 相位 cloak | 战斗 | 开战首回合，绑定卡组全体闪避 +15% |
| `passive_salvage_drone` | 打捞无人机 | 采集 | 驻扎/采集时，额外 +1 低阶材料/周期 |
| `passive_convoy_guard` | 护航协议 | 均衡 | 绑定卡组耐久损耗 −10% |
| `passive_rift_tuning` | 裂隙调谐 | 战斗 | 对 Entropy 标记敌人伤害 +10% |

船型由蓝图固定 1 个主被动；模块可解锁第 2 被动槽（后 MVP）。

### 3.5 舰桥舰队组件（Bridge Fleet Carousel）

**产品决议**（UI 细则见 [09-figma-ui.md](09-figma-ui.md)）：

1. 舰桥**删除**与探索度、信用点并列的「并行」统计卡；并行信息并入舰队区。  
2. 「当前卡组」面板保留在主战斗卡组上方，展示 5 人编制。  
3. 其下方的「并行中行动」改造为 **舰队组件**：**多张舰队卡片 + 水平滑动**。

| 阶段 | 行为 |
| --- | --- |
| **MVP 过渡** | 仅 1 艘开拓舰；仍用滑动容器 UI，单卡占满或居中，字段与多舰一致 |
| **后 MVP** | `FleetState.ships[]` 每舰一卡；左右滑动浏览；卡面显示舰型、绑定 deck、行动状态、驻扎/航行 |

单张舰队卡片最小信息：

```text
┌─────────────────────────┐
│ [舰型图标]  舰名          │
│ 卡组：{deckDisplayName}  │
│ 状态：采集中 / 空闲 / …   │
│ [────── 周期进度 ──────]  │  ← Running 时
└─────────────────────────┘
```

交互：

- 点击卡片 → `ShipScreen` 或 `FormationScreen`（聚焦该舰绑定 deck）。  
- 空闲槽位（已解锁泊位无舰）显示虚线「建造新舰」卡，跳转造船（后 MVP）。  
- 并行上限 `busy/max` 在组件标题行展示一次即可（如「舰队 · 2/3 行动中」），**不再**重复出现在顶栏统计区。

## 4. 驻扎采集（Stationed Harvest）

### 4.1 语义

| 项 | 定稿 |
| --- | --- |
| 前提 | 星球（或 `StellarBody`）上关联区域 **已 Cleared** |
| 操作 | 将 **1 艘已绑定编队的舰船** 设为「驻扎」 |
| 行为 | 等同在该星球节点运行 **Gather** / 低强度 **AutoCombat**（按节点类型）；占用该舰 + 编队 |
| 切换 | 召回驻扎需短冷却或即时（可配置）；召回后可改派战斗 |
| 离线 | 遵循 `04` 离线规则；驻扎舰参与离线结算 |

### 4.2 与卡关奖励循环

- 普通区驻扎：基础矿  
- **Gate 区** 驻扎：解锁**稀有副产物**（概率低于首通，高于普通区）  
- 多舰驻扎：不同 cleared 星球可并行，受**舰队数量**限制

### 4.3 UI 叙事

> 「 frontier 前哨已清除威胁。派遣工勘舰常驻轨道，可稳定回收航材。」

### 5.2 第七前沿：区域 × 主导敌方阵营

| 区域 | 主导敌方阵营 | 敌方叙事 | 典型编制（5 槽语义） |
| --- | --- | --- | --- |
| **外缘带** | 佣兵 + 卫队叛逃小股 | 劫掠巡逻 | 1 战士前 + 1 机械师 + 2 刺客 + 1 药剂（低阶） |
| **矿脉支线** | 商盟武装 + 佣兵 | 矿权争夺 | 2 异变前 + 1 术士 + 2 战士 |
| **量子裂隙** | **熵雾教团** | 相位仪式守卫生 | 2 术士后 + 2 刺客 + 1 异变（命中/相位 buff） |

### 5.3 敌方阵容设计原则

1. **每区 1 个主机制标签**（穿甲、相位、DoT、重甲、混合）与 `00` §6 威胁表一致；  
2. 同阵营敌人共享 **AI 倾向**（教团优先后排，残舰优先集火低耐久）；  
3. Gate 区敌方可带 **机制抗性**（须用对的舰船被动或卡牌构筑）；  
4. Boss 战至少 **2 阶段语义**（HP 阈值换技能或召唤），全自动结算内用脚本配置。

## 6. 星域探索度（Exploration Progress）

### 6.1 定义

| 项 | 定稿 |
| --- | --- |
| **探索度（%）** | 单星域独立；表示玩家对该星域「航行世界」的熟悉与覆盖程度 |
| **增长** | 在星域团块内 **航行时间**、**雷达揭示面积**、**发现新星球** 共同贡献 |
| **核心体验** | 待得越久，**发现新星球的概率越高**（非保证线性解锁） |

建议公式形状（实现可调参）：

```text
explorePoints =
    cruiseSecondsInSector × kTime
  + newTilesRevealed × kTile
  + newBodiesDiscovered × kBody

explorePercent = floor(explorePoints / sectorExploreTarget × 100)
```

| 参数 | 语义 |
| --- | --- |
| `sectorExploreTarget` | 该星域「100%」所需点数；随星域大小配置 |
| 软上限 | 100% 为「常规完成线」；允许继续积累触发 **>100%** 事件池 |

### 6.2 分段解锁

| 探索度 | 解锁内容 | 叙事 |
| ---: | --- | --- |
| **0–49%** | 雷达扫图、普通星球、基础 NPC | 「前沿侦察」 |
| **50%** | **星域主星（Capital Hub）** + **该星域阵营商店** | 「航道锚点已确认，商会愿开放货架」 |
| **51–99%** | 侧翼星球、卡关区坐标提示、订单刷新 | 「高密度区仍有未标定天体」 |
| **100%** | **常规星域 Boss** 战入口（若未击杀） | 「威胁核心已暴露」 |
| **>100%** | **超探索事件池**（见 §6.3） | 「读数异常：相位重叠上升」 |

隐藏设定（文案层，不强制一次实现）：

- 100% Boss 可能有 **弱相位** 或 **环境词缀** 预告；  
- >100% 不显示精确百分比亦可，仅显示「深度扫描 / Over-scan」档位。

### 6.3 探索度 >100% 事件池

按权重随机（可叠加冷却）：

| 事件类型 | 示例 | 奖励/风险 |
| --- | --- | --- |
| **虫洞（Wormhole）** | 短距跳跃或误入高危子区 | 省信标 / 遇强敌 |
| **秘境（Secret Realm）** | 限时副本空间 | 稀有蓝图、相位核心 |
| **神秘 NPC** | 行商、流浪工程师、教团叛逃者 | 任务、图纸、情报 |
| **隐藏 Boss** | 未标定锚点守卫 | 唯一模块、成就 |
| **熵雾潮汐** | 全星域 debuff 数小时 | 高风险高掉落窗口 |
| **残骸 jackpot** | 一次性打捞 | 大量基础资源 |

事件须 **可拒绝** 或 **可延后**；不得硬锁主线。

### 6.4 与雷达 / 航行的关系

- 探索度 **不替代** 雷达揭示：仍须移动才能扫到新点；  
- 探索度 **不替代** 五种航网状态（`20` §3）：域内熟悉度 ≠ 跨域通航；  
- 探索度 **提高** 「随机生成候选星球」的权重（在 `20` 团块密度公式上乘系数）；  
- 主星 / 阵营商店坐标在达 50% 前 **不可交易解锁**，可通过任务预告。

## 8. 与现 MVP 的差异与迁移（§12）

| 现状（代码） | 目标设定 | 迁移建议 |
| --- | --- | --- |
| 单 `ShipEntity` 主舰 | 多舰 `FleetState` | 首艘迁移为 `ShipInstance[0]` |
| 多 `DeckEntity` 不绑舰 | 一舰一 deck | 卡组挂到 `boundDeckId` |
| 区域列表 Explore | 星图 + 探索度 | 第七前沿已加航网恢复% + 五种状态；地图为 M2 域内网 |
| 采集 / AutoCombat 不绑星球 | 驻扎 `Stationed` | 通关后 UI 增加「驻扎」 |

**MVP 可保留**：单主舰 + 多卡组为 **Solo 简化模式**，叙事上解释为「尚未扩建港口第二泊位」；文档与 UI 逐步切到舰队语义。
