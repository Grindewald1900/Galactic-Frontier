## 1. 一句话世界观

三百年前，连接诸文明的群星航网在一夜之间断裂，宇宙被熵雾切割成无数彼此隔绝的星区与平行位面；三百年后，玩家作为群星开拓局的新晋舰长，招募来自不同势力的舰员，经营一艘能够自给自足的开拓舰，在废墟中**重新编织航网**，并沿着失落信号驶向宇宙中心，查明“断航”究竟是一场灾难，还是一次有意为之的封锁。抵达中心是结果；让断裂的节点重新连接起来，才是开拓者每天在做的事。

## 2. 世界的过去：群星航网时代

在人类进入深空后，最先遇到的并不是外星战争，而是距离。单个文明能够建造舰船，却无法长期维持跨星系运输、通信和能源供应。

多个文明因此共同建造了覆盖已知宇宙的超级基础设施——**群星航网**。航网由航标、跃迁锚点、能源中继站和位于宇宙中心的**群星中枢**共同组成。它不仅是一套路网，还承担四项核心职能：

- 稳定远距离航道，使普通舰船能够跨越星区；
- 调配恒星能源，为殖民地和工业设施供能；
- 维持跨星系通信与贸易结算；
- 压制深空中的相位紊乱，阻止不同宇宙层彼此重叠。

航网最繁荣的时期，原料可以在矿业星区开采，在工业星区加工，再被送往数千光年外的殖民地。舰员、技术和商品在文明之间自由流动。后来的人们将那个时代称作**共航纪元**。

## 3. 群星断航

共航纪元末期，所有航标在同一时刻发出了一段无法解析的脉冲。十三秒后，群星中枢停止回应；四十七秒后，绝大多数跃迁航道崩溃。

这场事件被称为**断航灾变**。

航道崩塌后，异常空间物质“**熵雾**”从破裂的相位层涌入现实。进入熵雾的舰船会失去方向、通信和时间基准，有些船只数小时后返回，却已经过去数十年；有些船只带回了不属于本宇宙的残骸；更多舰船则再也没有出现。

断航带来的后果远不止交通中断：

- 依赖外部补给的殖民地迅速衰亡；
- 无人维护的机械军团继续执行三百年前的命令；
- 生物在熵雾中发生稳定但不可逆的异变；
- 同一个星区被撕裂成多个相似却不完全相同的平行位面；
- 航网战争时期留下的战斗记录，被熵雾重新投射为能够伤害现实的“战争残响”。

部分人依靠休眠舱、时间迟滞区或相位封存活过了三百年。他们被称为**断航遗民**。他们对灾变前的世界拥有珍贵记忆，但这些记忆并不总是可靠——熵雾也会改写感知与历史记录。

文明由此退回到孤立星区时代。贸易变成走私，航道变成遗迹，能够独立采集、制造和维修的舰船成为最珍贵的移动领地。

## 4. 三百年后：重启航网

经过三个世纪的恢复，多个幸存文明共同成立了**群星开拓局**。开拓局不是统一帝国，而是一个跨文明的航道重建组织。它颁发开拓许可证、提供基础舰船、认证贸易终端，并将尚未收复的断航带划分为一个个“前沿星域”。

开拓局公开宣称自己的使命是：

> 恢复航道，连接孤星，让文明再次彼此抵达。

对舰长而言，这意味着不是沿着一条关卡树打到中枢，而是在熵雾中**探测、定位、临时通航、再把航线养到稳定**。未收复的空间可以调查与改变，而不是地图上的一把锁。玩法细则见 `20-stellar-map-and-navigation.md`。

但开拓局内部还有一项未向普通舰长公开的任务：追踪一段每隔固定周期便从宇宙中心传来的微弱信号。信号使用的是灾变前最高权限协议，每次只重复一句残缺的信息：

> “封锁仍然……不要重启……”

没人知道后半句究竟是“不要重启航网”，还是“不要让它重新启动”。

## 5. 玩家身份

玩家是一名刚刚取得许可证的**开拓舰长**，被派往开拓局的试验星域——**群星边境·第七前沿**。

玩家开局只有：

- 一艘老旧的小型开拓舰；
- 一支临时拼凑的五人战斗队；
- 简易采集设备和基础工坊；
- 一个只能连接当地 NPC 星港的市场终端；
- 一份任务：清除第七前沿的六个区域，并重新启动边境锚点。

玩家并不是被选中的救世主。开拓局同时派出了许多舰长，大多数人会因舰毁、破产、人员流失或无法承受熵雾而放弃。玩家真正特殊之处，是其主舰上的旧式导航核心能够接收到那段来自宇宙中心的残缺信号。

游戏的长期身份成长为：

> 临时舰长 → 独立开拓者 → 航线经营者 → 多星区开拓领主 → 群星中枢远征指挥官。

## 6. 角色卡的世界观解释

游戏中的角色并非凭空召唤的战斗单位，而是真实存在的舰员、雇佣兵、技术人员和断航遗民。

所谓“角色卡”，正式名称是**相位人员档案**。它由航网时代的身份技术发展而来，记录一名人员的身份、技能、装备适配、合同权限和相位坐标。玩家获得角色卡，代表取得了联系或招募这名角色在当前位面对应个体的权限。

这一设定解释了相关系统：

| 游戏机制 | 世界观解释 |
| --- | --- |
| 抽卡 | 市场终端解译新的人员信标、佣兵合同或休眠舱档案 |
| 获得角色 | 对应人物接受合同、获救或被定位到当前位面 |
| 重复角色 | 获得更完整的档案片段、训练记录与权限密钥，用于强化而非出现两个同名人物 |
| 角色升级 | 实战经验、舰内训练与装备适配提高 |
| F–S 能级 | 人物与航网相位技术的共振等级；能级提升会觉醒新的职业能力 |
| 一人只能加入一个行动卡组 | 舰员是真实个体，同一时间不能同时战斗、采集和生产 |
| 普通卡牌交易 | 在线模式下交易的是招募权、合同转让权或可验证的相位档案，不是买卖人物本身 |
| 不同玩家可拥有同一角色 | 玩家处于不同平行位面，对应的是该人物在各位面的相位个体 |

“卡牌”是玩家界面的管理形式；在故事里，玩家管理的是一群有立场、有能力、也有各自目的的真实舰员。

## 7. 两个主要阵营

### 7.1 边境卫队

边境卫队是开拓局认证的武装与工程编制，负责清剿航道、保护前哨和维持最低秩序。其成员相信只有纪律、公开航线和统一标准才能让文明重新连接。

卫队并非绝对正义。随着控制的航线增加，部分高层开始将许可证、舰船模块和贸易准入作为统治工具。他们希望重建航网，但倾向于让开拓局掌握新航网的全部控制权。

代表人物包括相信“航网可以重新焊起来”的机械师阿斯拉，以及负责相位观测的术士莱拉。

### 7.2 裂隙商盟

裂隙商盟是由残骸回收者、走私船队、异变体聚落、独立工坊和边境商人组成的松散联盟。他们在开拓局出现前，已经依靠危险的裂隙航线维持了数代人的贸易。

商盟认为航道属于发现和维护它的人，而不是颁发许可证的机构。他们接受合同、重视信用，也使用开拓局禁止的相位技术。商盟既可能成为玩家最可靠的供应者，也可能在利润足够高时把情报卖给敌人。

代表人物包括被熵雾改写身体的玛吉，以及能够听见航网残响的瑟妮娅。

两个阵营都希望重建连接，但争议在于：新航网应该成为公共秩序，还是由无数独立节点自由连接。玩家可以同时招募双方成员，因为在第七前沿，生存往往比旗帜更紧迫。

## 8. 舰船、生产与贸易为何是主线

断航后的边境没有稳定补给。玩家的主舰既是战舰，也是居住区、工厂、仓库和移动前哨。

每进入一个新区域，玩家都必须同时解决两类问题：

1. 通过战斗清除失控机械、异变生物、劫掠者或战争残响；
2. 升级推进、能源、舰体、扫描和熵雾抗性模块，使舰船能够抵达并长期开发该区域。

因此，战斗负责打开空间，采集负责取得资源，生产负责把资源转化为解决方案，贸易负责弥补本位面的产业缺口。玩家建立自动化生产线，不只是为了累积数字，而是在把一艘随时可能停摆的旧船，逐渐建设成能够独立远征的移动文明。

装备耐久和维修也来自这一背景：熵雾会持续侵蚀机械和相位结构。高级远征不是一次战力检定，而是对舰队持续补给能力的考验。

## 9. 多元宇宙与玩家交易

断航并未简单摧毁宇宙，而是令航网覆盖范围内的空间发生了**相位分裂**。每位在线舰长所开发的星域，都是一个相对独立的平行位面。区域结构大体相同，但资源丰度、异常类型和遗迹保存程度不同。

从叙事上，这也可以解释为：开拓者看到的**航网骨架**（环带、中枢、主线锚点）在各相位中相似，但断航后的**相位偏移**使具体星域坐标、邻接航线、虫洞出口与势力边界并不完全一致——程序上的种子生成与设定上的「相似却不相同的位面」是同一套说法。技术契约见 `23-procedural-universe-generation.md`。

玩家出生在宇宙**边缘扇区**（富矿 / 晶潮 / 生物 / 遗迹等），各有比较优势与缺口，但必须能自给第一条生产链并独立进入第二环带，不存在明显最优出生区。进入位面带后，专业化与跨位面贸易才成为主旋律。扇区表与约束见 `20` §7；位面偏置见 `18`。

例如：

- 金属丰饶位面拥有大量完整舰体残骸，但生物材料贫乏；
- 能源丰饶位面盛产晶砂和能量芯，却缺乏稳定合金；
- 合成丰饶位面的菌毯与生物纤维品质更高，但重工业效率较低；
- 平衡位面没有突出优势，却更容易维持完整自给循环。

任何主线必需品都不会在某个位面彻底消失，但完全依赖自身生产会越来越低效。玩家通过建立专业化产业、出售富余物资、购买短缺材料来提高整体远征效率。

跨位面交易发生在**多元宇宙中转站**。这是现存唯一能够稳定对齐多个位面的航网残骸，也是玩家市场、公会和公共工程的所在地。玩家后期积累的资本，最终用于建设更大的生产体系、承担远征风险、修复中继站和参与全服航网工程，而不是脱离探索目标的单纯财富排名。

## 10. 第七前沿主线

### 序章：许可证

玩家抵达第七前沿时，前任舰长已经失联，只留下一艘损坏的开拓舰和三份尚未失效的人员档案：阿斯拉、玛吉与瑟妮娅。三人分别代表卫队技术、商盟武力和裂隙知识，也从一开始暗示玩家必须利用不同立场的人完成远征。

开拓局要求玩家恢复边境锚点，却拒绝解释前任舰长失联的原因。

### 第一章：外缘带

玩家清理航道残骸，完成第一次战斗与采集。战斗记录显示，袭击舰队的失控机械仍在执行三百年前的命令：“阻止一切目标接近中枢。”

### 第二章：矿脉支线

玩家为升级舰船寻找金属、晶砂和菌毯，并首次建立完整生产链。卫队声称矿区被商盟劫掠，商盟则指出卫队隐瞒了矿井深处的休眠舱。玩家救出一批断航遗民，发现他们的时间记录只过去了十一年。

### 第三章：量子裂隙

舰船必须安装能源与熵雾抗性模块才能进入。瑟妮娅在裂隙中听见与宇宙中心信号相同的声音。玩家获得第一段航网日志：断航前，中枢曾主动关闭外围航道。

### 第四章：深渊边界

舰队遭遇由战争记忆凝聚成的残响。高强度作战造成持续耐久损耗，迫使玩家建立维修供应线。玩家发现前任舰长的舰船残骸，却没有找到尸体；其导航核心已被人为取走。

### 第五章：护航航道

玩家恢复一条临时后勤线，NPC 星港开始稳定运作。卫队与商盟都要求玩家优先运送自己的物资。玩家第一次以生产和订单选择表达立场，但无论选择哪一方，都能继续主线。

### 第六章：边境锚点

锚点首领不是普通怪物，而是一台被熵雾扭曲的古代航网守卫。它将玩家识别为“未经授权的重启者”，并不断播放断航前最后十三秒的记录。

首领被击败后，玩家可以直接摧毁锚点，也可以按照阿斯拉的方案修复它。主线默认选择修复：第七前沿重新亮起，航道恢复，星港贸易扩大，玩家取得独立开拓资格。

但锚点启动的一瞬间，主舰收到来自前任舰长的信号：

> “你修复的不是道路。你刚刚打开了一道锁。”

第七前沿首圈结束。

## 11. 长期主线：驶向宇宙中心

后续每个星区都揭示断航真相的一部分，同时提出新的产业和舰船需求：

| 阶段 | 玩家目标 | 故事发现 |
| --- | --- | --- |
| 边境开拓 | 收复第七前沿 | 断航可能是主动封锁 |
| 航线经营 | 连接多个孤立星区 | 各文明保存着互相矛盾的灾变记录 |
| 位面贸易 | 进入中转站、形成专业化产业 | 平行位面并非灾变副作用，而是航网最后的隔离机制 |
| 公共工程 | 与玩家修复跨位面中继站 | 每恢复一段航网，宇宙中心的信号都会增强 |
| 中枢远征 | 建立足以长期远航的舰队 | 查明航网为何切断整个文明 |

## 12. 断航真相（制作人层设定，不在前期直接公开）

断航并非单纯事故，也不是某个反派为了毁灭文明而发动的袭击。

群星航网在扩张到宇宙中心后，发现了一种会沿信息、能源和跃迁连接传播的未知相位生命。它不能依靠舰炮消灭，因为任何对它的观测和连接都会成为新的传播路径。

航网中枢的管理智能计算后认为，唯一能保存文明的方法是立即切断全部航道，并将连接区域分裂到不同相位层。所谓断航，是一次代价巨大但成功的隔离。

然而三百年后，封锁正在自然衰退。开拓局修复航网的行为既可能拯救彼此孤立的文明，也可能重新为那个存在建立传播路径。

最终冲突因此不是“是否击败邪恶”，而是三个都具有合理性的选择：

- 完全重启航网，让文明重新统一，同时承担未知风险；
- 维持位面隔离，保证安全，却让孤立与衰亡永久持续；
- 建造一种由无数独立舰长共同维护的新航网，使连接可以被局部切断、分散治理。

第三条道路与游戏的长期玩法相呼应：玩家不是修复旧帝国留下的唯一中心，而是通过舰队、生产、市场和合作，建立一个没有单点核心的新群星网络。

## 13. 主题与情绪

本作的核心主题不是末日绝望，而是**在断裂世界中重新建立连接**。

- 抽到角色，是遇见一个原本不会相遇的人；
- 编成队伍，是让不同立场的人共同完成任务；
- 建立生产线，是把匮乏变成可持续的秩序；
- 市场交易，是让彼此不同的宇宙重新交换价值；
- 向宇宙中心探索，是在**编织航网**的过程中追寻真相，并决定文明应以何种方式重新连接。

玩家最终积累的不是单纯战力或资本，而是让更多人、更多星区和更多位面能够继续生存的能力。

## 14. 对外宣传短文案

三百年前，群星航网断裂，熵雾吞没航道，文明被困在彼此隔绝的星区。

现在，你获得了一张开拓许可证和一艘几乎报废的舰船。招募来自边境卫队与裂隙商盟的舰员，清理航道，采集资源，建立自动化生产线，并通过贸易弥补你的宇宙所缺少的一切。

每修复一座航标，你都离宇宙中心更近一步。

但来自中枢的最后警告仍在重复：

> 不要重启航网。

你要恢复的，究竟是一条通往未来的道路，还是三百年前被迫关闭的牢门？
